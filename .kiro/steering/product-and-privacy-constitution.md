1. **Zero Cloud Telemetry:** Never add third-party analytics, tracking pixels, external AI inference calls, or remote error-reporting SDKs.
2. **Defensive-Only Security Posture:** All permission analysis, binary EXIF extraction, and secret scanning exist strictly to audit, protect, and harden user privacy. Never generate offensive payloads or exploits.
3. **Swiss-Precision Optical UI:** Use obsidian dark laboratory surfaces (`#070B14`, `#0E1525`), high-contrast semantic indicators (Emerald = Contained/Clean, Amber = Elevated Risk, Crimson = Critical Leak), tabular monospace telemetry, and crisp `lucide-react` SVG icons only. Never use emojis as UI icons.
4. **Chaos Resilience:** Every binary parser (`DataView`) and XML/text analyzer must clamp offsets safely and degrade cleanly on malformed inputs without crashing the React tree.
