# PhantomGlass v2.0 Product & Zero-Leak Privacy Constitution

## Core Identity
- **Project:** PhantomGlass v2.0 — 7-Organ Zero-Trust Mobile (Android 8–17 & Apple iOS), Binary Media, Secret & Columnar Dataset Exorcist (Kiroween 2026 Frankenstein Category)
- **Author:** HM Shihabuddin Jashory (`@jashory`)
- **Non-Negotiable Architecture Law:** `0` bytes of user photos, `AndroidManifest.xml`, iOS `Info.plist` / `PrivacyInfo.xcprivacy`, CSV/TSV datasets, or secret text may EVER leave local browser RAM or local stdio MCP memory.

## Engineering Rules
1. **Zero Cloud Telemetry:** Never add third-party analytics, tracking pixels, external AI inference calls, or remote error-reporting SDKs. Every file inside `web/src/engines/*.ts` must contain zero `fetch(` or `XMLHttpRequest` calls.
2. **Defensive-Only Security Posture:** All permission analysis, binary EXIF/PDF extraction, columnar dataset shrinking, and secret scanning exist strictly to audit, protect, and harden user privacy. Never generate offensive payloads or exploits.
3. **Swiss-Precision Optical UI:** Use obsidian dark laboratory surfaces (`#070B14`, `#0E1525`), high-contrast semantic indicators (Emerald = Contained/Clean, Amber = Elevated Risk, Crimson = Critical Leak), tabular monospace telemetry, and crisp `lucide-react` SVG icons only. Never use emojis as UI icons.
4. **Chaos Resilience:** Every binary parser (`DataView`), iOS plist parser, CSV columnar slicer, and XML/text analyzer must clamp offsets safely and degrade cleanly on malformed inputs without crashing the React tree.
